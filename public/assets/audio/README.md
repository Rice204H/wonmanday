# Một chút dịu dàng

`garden-piano.wav` is an original instrumental miniature generated specifically for this project. Its melody, chord arrangement, piano-like tones, and room echoes are synthesized from mathematical oscillators. No recording, sample, or external musical work was used.

- Format: WAV, mono, 16-bit PCM, 22,050 Hz
- Duration: 36 seconds, gently faded at both ends for repeated playback
- Player: manual playback only, looping, with an initial volume of 30%
- Provenance: composed and synthesized for the Wonmanday website by the project development assistant on 2026-10-20

The project may use, edit, and distribute this original audio together with the website. The synthesis source is kept in the workspace at `work/generate_garden_piano.py`.
